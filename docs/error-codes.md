# Meldingsnummers

Meldingsnummers zijn vaste identificaties van foutsoorten. Gebruik hetzelfde nummer telkens wanneer dezelfde fout wordt getoond; maak dus geen nieuw nummer per aanvraag. Zo kunnen gebruikers een probleem eenduidig doorgeven.

| Nummer | Betekenis |
|---:|---|
| 12544 | Bedrijf of website niet beschikbaar |
| 18403 | Aanmelden bij dit bedrijf niet mogelijk |
| 21607 | Aanvraagmethode niet toegestaan |
| 32719 | Databaseconfiguratie ontbreekt |
| 33826 | Database niet bereikbaar |
| 40152 | Geen toegang |
| 45878 | Ongeldige aanvraag of beveiligingstoken |
| 50631 | Registratie tijdelijk niet beschikbaar |
| 61724 | Vertalingen konden niet worden gecontroleerd |
| 72805 | Template niet beschikbaar |

Ken nieuwe nummers toe door deze lijst te controleren en een nog ongebruikt nummer van vijf cijfers vast te leggen.

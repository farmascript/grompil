Grompil Bookmarks Privacy Policy

Last updated: 11 November 2026

What the extension does

Grompil Bookmarks creates and refreshes two browser bookmark folders from the navigation and module access available in the user's signed-in Grompil URL Manager. Synchronization starts only when the user clicks the extension's sync button.

Information accessed and how it is used

After the user starts a sync, the extension checks the active tab to locate the Grompil URL Manager. It reads the selected language, company context, permitted module list, and URL Manager pages, groups, and links. This may include user-created link titles and destination URLs. It requests the required navigation and access data from that same Grompil website, using the user's existing authenticated HTTPS session. This information is used only to create the browser bookmarks requested by the user.

Local storage

The extension stores the browser bookmark IDs of the two folders it created, separated by Grompil website origin. It uses these IDs to replace the contents of those folders during a later sync. The generated bookmarks themselves are stored by the browser as ordinary bookmarks. Navigation data is held temporarily while the sync runs. The extension does not read or store passwords or authentication cookies.

Sharing and third parties

The extension does not send navigation data to third-party services. It does not include analytics, advertising, or data brokerage. Requests made during synchronization go only to the Grompil website open in the active tab.

User control and retention

Synchronization is manual. Users can remove the generated folders from their browser bookmarks at any time. The extension uses its locally stored folder IDs only to manage those generated folders on a later sync. Uninstalling the extension removes its extension storage; bookmarks remain under the user's control in the browser.

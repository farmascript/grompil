# Chrome Web Store submission checklist

## Prepared in this repository

- English extension name and description in `manifest.json`.
- English popup and runtime messages.
- Grompil extension icons in 16, 48, and 128 pixel sizes.
- Store screenshot 1 in `store-assets/screenshot-1.jpg` (1280 × 800).
- Draft store copy and permission justifications in `STORE_LISTING.md`.
- English privacy policy in `PRIVACY_POLICY.html`.
- English installation and sync instructions in `README.md`.

## Complete in the Chrome Web Store dashboard

1. Publish `PRIVACY_POLICY.html` at a public HTTPS URL and enter that URL in the
   privacy policy field.
2. Upload `store-assets/screenshot-1.jpg` as the first store screenshot. Add a
   second screenshot of the extension popup if desired.
3. Enter the store copy, category, support contact, single-purpose explanation,
   permission justifications, and truthful data use declarations.
4. Upload the packaged ZIP from the release process and submit it for review.
5. Keep the publisher contact email monitored for review notices and policy
   requests.

Do not submit until the privacy policy URL is public and the final privacy
declarations have been checked against the package and its actual behavior.
